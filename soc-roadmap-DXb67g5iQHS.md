# Become a SOC Analyst in 60 Days

**Realistic. Practical. Job-Ready.**

60 days to build a strong foundation and practical skills. Continue hands-on
practice beyond 60 days to become job-ready.

## Day 1-7: Networking Fundamentals

- IP Addressing, Subnetting, DNS
- TCP/UDP, Ports, HTTP/HTTPS
- OSI Model, Packet Flow, Common protocols

**Focus:** Understand how networks work. Essential for log analysis & attacks.

## Day 8-14: Linux Fundamentals

- Linux commands (`ls`, `cd`, `cat`, `grep`, `awk`, `sed`)
- File system, Permissions, Users & Groups
- Processes, Services, Logs (systemd, journald)
- Shell scripting basics (Bash)

**Focus:** Comfortable with Linux CLI & system investigation.

## Day 15-21: Cyber Security Fundamentals

- CIA Triad, Security Principles
- Types of Attacks (Phishing, Malware, DDoS, etc.)
- Threat Actors, Vulnerabilities, Exploits
- Introduction to MITRE ATT&CK

**Focus:** Understand core security concepts & how attacks work.

## Day 22-30: SIEM Management

- What is SIEM & how it works
- Splunk / ELK basics (search, queries, filters, fields)
- Creating alerts, dashboards, reports
- Common log sources & log types

**Focus:** Learn to collect, search & visualize logs in a SIEM.

## Day 31-40: Log Analysis

- Windows Event Logs (Security, System, Application)
- Firewall Logs, DNS Logs, Web Logs
- Authentication Logs (Success, Failure)
- Log normalization & correlation

**Focus:** Read logs like a detective and find what matters.

## Day 41-48: Threat Detection

- Indicators of Compromise (IOC)
- MITRE ATT&CK in detection
- Use case: brute force, malware, phishing, lateral movement
- Building detections & use cases in SIEM

**Focus:** Detect threats using logs, IOCs & MITRE ATT&CK.

## Day 49-55: Incident Response Basics

- Rapid Response Lifecycle
- Detection -> Analysis -> Containment -> Eradication -> Recovery
- Triage, Investigation, Documentation
- Tools: VirusTotal, IP lookup, WHOIS, etc.

**Focus:** Respond to incidents using a structured process.

## Day 56-60: Capstone: Practice & Projects

- Hands-on labs (TryHackMe / Hack The Box SOC)
- Investigate real-world scenarios
- Build mini-projects & detection rules
- Create a portfolio to showcase your skills

**Focus:** Apply everything you learned. Build confidence.

## After 60 Days - Keep Learning & Practicing

- Learn Python for security automation
- Join CTFs & SOC communities
- Earn certifications (e.g. CySA+, Security+)

> Consistent practice is the key to becoming a great SOC Analyst.
